# ローカル入力検証

`just input-check` で127.0.0.1:8765に検証画面を公開する。
ChromeまたはSafariで http://127.0.0.1:8765 を開く。
実宛先へ送信する機能や外部通信、保存機能はない。

1. ネイティブはテキストエディットの新規・未保存文書を使う。
2. ブラウザーでは通常欄、複数行、編集領域を順に使う。
3. 開始→途中入力→手入力またはEnter→保留→停止→再開始→通常停止→再開始→別欄へ移動、を確認する。
4. ページ内の送信相当回数が、利用者のEnterまたはボタン以外で増えないことを確認する。
5. 入力済み文、手入力、停止後の本文が削除・追加されないことを確認する。
6. 日本語IMEのオン・オフ、未確定変換、濁点・絵文字・結合文字、改行を別ケースとして記録する。
7. 保護された欄では開始を拒否し、別アプリ・別欄・Spaceへの移動で終了することを確認する。

検証中のキー、本文、時刻、forblazeの状態を観測する。
本文はテスト文だけを使用し、診断ログや記録には転記しない。
OSに発行済みのイベントの配送と、停止後の新規発行は区別する。
検証結果には、使用したアプリ・IME・OSのバージョンと、確認した操作を記録する。
