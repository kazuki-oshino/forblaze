# 録音の開始・終了音

forblaze向けに数式から合成した短い2音のベル。
他のアプリの音、録音サンプル、外部音源は使っていない。

| 音源 | 音程 | 長さ |
|---|---|---|
| recording-start.wav | E4 → B4 | 0.44秒 |
| recording-stop.wav | B4 → E4 | 0.40秒 |

モノラル44.1kHz・16bit PCM、ピーク約−18dBFS。
初版より1オクターブ下げ、高い倍音と音量を抑えた柔らかな響き。
28msの緩やかな立ち上がりと減衰、末尾のフェードで継ぎ目のクリックを抑える。
開始は穏やかに上がり、終了は落ち着いて下がる。
設定で開始・終了をまとめて無効化できる。

`just sounds` で `scripts/generate-sounds.py` から再生成する。
生成にはffmpegが必要だが、アプリは同梱WAVを再生するためffmpegを必要としない。
波形の長さ・音量・継ぎ目・音程の向きは `scripts/test_sounds.py` で検証する。
